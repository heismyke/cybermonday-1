# Images for ONDE (Cyber Monday Site 1)

Generate these with any AI image tool (ChatGPT, Gemini, Midjourney…), then:

1. Convert to **WebP** and compress to **under 200 KB** each (squoosh.app or tinypng.com).
2. Save them with the **exact file name** below in `public/images/`.
3. Commit and push. The site picks them up automatically. Until then, each slot shows a dark grey block.

**Style to keep for every image:** minimal dark studio product photography, matte black over-ear headphones, near-black background (#0a0a0b), one soft rim light, a subtle hint of lime-green (#c8ff3e) light, lots of negative space, sharp details, no text, no logos, no people.
